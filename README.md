# Open Attribution License (OAL)
**An independently developed software license by exevectorr.**
The Open Attribution License (OAL) is a custom software license designed to protect original creator attribution while allowing software to be used, modified, distributed, and commercially exploited.
OAL aims to give developers freedom to work with software while ensuring that the original creator receives proper recognition and that modifications remain open source under OAL 1.1.

---

## Versions
| Version | Description |
|---|---|
| OAL 1.0 | Original attribution-focused license. |
| OAL 1.1 | Introduces mandatory source-code disclosure for distributed modifications. |

### OAL 1.0
The original version of OAL.
- Allows commercial and private use.
- Allows modification and redistribution.
- Requires preservation of original attribution.
- Does not require modified projects to be open source.

### OAL 1.1
Introduces a mandatory open-source requirement.
- All OAL 1.0 permissions remain, subject to the updated terms.
- Distributed modifications must include their corresponding source code.
- Modified Works must remain under OAL 1.1.
- Closed-source distribution of modified versions is prohibited.
- Private modifications do not need to be published.

---

## Core Principles

### 1. Original Attribution
The original copyright holder's attribution must remain intact.
Original creator credits and copyright notices must not be removed, replaced, or misrepresented.

### 2. Freedom of Use
OAL permits:
- Personal use.
- Commercial use.
- Modification.
- Redistribution.
- Copying.
- Studying.
- Creating derivative works.

### 3. Open-Source Modifications (OAL 1.1)
Any Modified Work distributed under OAL 1.1 must have its complete corresponding source code made available to recipients.
Modifications cannot be distributed as closed-source software.

### 4. Commercial Freedom
OAL permits commercial use, including selling software and incorporating it into commercial products.
Commercial use does not exempt anyone from the license requirements.

## License Comparison
| Permission / Requirement | OAL 1.0 | OAL 1.1 |
|---|---|---|
| Private use | Yes | Yes |
| Commercial use | Yes | Yes |
| Modification | Yes | Yes |
| Redistribution | Yes | Yes |
| Original attribution required | Yes | Yes |
| Modified source code required when distributed | No | Yes |
| Same-license requirement | No | Yes |
| Closed-source modifications allowed | Yes | No |

## How to Use OAL
To apply OAL to your project:
1. Choose the OAL version you want to use.
2. Include the complete license text in your project.
3. Preserve the original copyright attribution.
4. Specify the license version in your README or project documentation.

Example copyright notice:

Copyright (c) 2026 exevectorr
Licensed under the Open Attribution License (OAL) 1.1.
See the LICENSE file for the complete license terms.

## License Versions and Compatibility
OAL 1.0 and OAL 1.1 are separate license versions.
Projects originally released under OAL 1.0 remain under OAL 1.0 unless their Copyright Holder explicitly relicenses them under OAL 1.1.
OAL 1.1 does not automatically change the licensing terms of existing OAL 1.0 projects.
